# 🐝 BargainBee – Smart Price Comparison Website

## 📌 About the Project

BargainBee is a simple and user-friendly price comparison website developed using HTML and CSS. The main purpose of this project is to help users compare product prices from different local stores and find the best available deals.

The website provides a simple interface where users can explore different product categories, check product prices, compare nearby stores, and view store information.

This project is developed as a first-year practical project to understand the basics of HTML and CSS.

## ✨ Features

- **Home Page:** Displays product categories and best deals.
- **Product Search:** Provides a search bar for products and brands.
- **Product Categories:** Includes Groceries, Electronics, Home, and Fashion.
- **Price Comparison:** Displays prices of the same product from different stores.
- **Product Details:** Shows product information, ratings, and available prices.
- **Store Location:** Displays store address, timings, and a map preview.
- **User Profile:** Displays user information, orders, wishlist, and other profile options.
- **Responsive Design:** Basic responsive layout for mobile and desktop screens.

## 🛠️ Technologies Used

- CSS3

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `BargainBee.html` file.
4. Double-click the HTML file.
5. The website will open in your browser.

## 🎯 Objective

The objective of this project is to create a simple price comparison website that demonstrates the use of HTML elements, CSS styling, navigation links, sections, forms, and responsive design.

## ⚠️ Note

This is a front-end academic project. Product prices and store details are sample data. Features such as live product searching, real-time price updates, user authentication, and location tracking are not connected to a backend.
